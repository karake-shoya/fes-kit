# 認証後画面のプレビュー手順（公開ルート `/` の一時差し替え）

2026-07-29 のダイアログのスクロール修正で確立した。2026-10-15 に Claude Code の自動メモリから移した。

## 何ができるか

Clerk 認証後の画面は preview ツールで開けない（`*.clerk.accounts.dev` へのリダイレクトがブロックされる）。
公開ルート `/` を一時的に差し替えると、認証が要るコンポーネントの**見た目**をブラウザで確かめられる。
動作（データの読み書き）の確認には使えない。

## 手順

1. `src/app/page.tsx`（`/`）を、検証したいクライアントコンポーネントをダミーデータで描画する一時ページに置き換える。
   - `/` は `src/proxy.ts` の `isPublicRoute` に入っている。中身は `redirect("/dashboard")` の5行だけなので、差し替えと復元が容易。
2. `preview_start` で開いて確認する。
   - dev サーバーがポート3000で既に動いていることがある。その場合は `preview_start` に `{url: "http://localhost:3000"}` を渡して相乗りする（Shoya のプロセスを落とさない）。
3. `page.tsx` を復元し、`git diff` が空になることを確かめる。

## 守ること

- `src/proxy.ts` には触らない。CLAUDE.md の「認証バイパスは事前承認なしに行わない」に抵触しないのは、この点による。
- `.claude/` 配下に一時ルートを作る案は proxy の変更が要るので使わない。

## 実績

2026-07-29 に、目視でしか気づけない sticky の粗（固定バーの裏にカードが隠れて「消えた」ように見える）を見つけた。
